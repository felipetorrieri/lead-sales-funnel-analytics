# Data Dictionary

| Column | Description |
|---|---|
| lead_id | Synthetic lead identifier |
| lead_date | Date the lead entered the funnel |
| origin | Acquisition/source channel |
| locadora | Synthetic rental partner |
| region | Geographic region |
| supervisor | Synthetic supervisor identifier |
| sdr | Synthetic SDR identifier |
| order_date | Date an order was created |
| credit_analysis_date | Date credit analysis started |
| approved_date | Date the lead was approved |
| formalized_date | Date the deal was formalized |
| signed_date | Date the deal was signed |
| stage | Deepest stage reached by the lead |
| gmv | Synthetic gross merchandise value |
| amount_paid | Synthetic amount paid |
| target_formalized | Target number of formalized deals |
| target_signed | Target number of signed deals |
| is_order | 1 if an order exists |
| is_approved | 1 if approval exists |
| is_formalized | 1 if formalization exists |
| is_signed | 1 if signature exists |
